# Sylvie TaskList v1 功能规划

## 技术栈

- 目标平台：仅 Windows 10 及以上
- React 18 + TypeScript
- Electron（主进程 / 渲染进程）
- 本地持久化：JSON 文件存储（用户目录下）
- 样式：Tailwind CSS
- 构建工具：Vite（渲染进程）+ Electron Forge（打包与开发流程）

## 界面布局设计

- 桌面软件模式（非网页式布局）
  - 自定义标题栏（`frame: false` 无边框窗口 + `-webkit-app-region: drag`）
    - 左侧：应用图标 + 应用名「Sylvie TaskList」
    - 右侧：Windows 风格窗口控制三键（最小化 / 最大化 / 关闭）
    - 关闭按钮悬停变红色（Windows 惯例）
    - 不放设置齿轮按钮，设置入口收在帮助菜单
  - 菜单栏（精简为两个菜单）
    - 任务：新建任务（`Ctrl+N`）、新建分组
    - 帮助：设置（`Ctrl+,`）、关于
    - 配置类功能（导入导出、主题等）全部收口到设置界面，菜单不重复
  - 工具栏（内容区顶部）
    - 搜索框（弹性宽度，支持 `Ctrl+F` 聚焦）
    - 筛选 tabs：全部 / 进行中 / 已完成
    - 排序下拉：自定义排序 / 按优先级 / 按截止时间 / 按创建时间
    - 「+ 新建任务」主按钮
  - 左侧分组侧边栏
    - 「全部」固定置顶 + 自定义分组列表
    - 存在归属「未分组」的任务时自动显示「未分组」入口
    - 分组行：颜色圆点 + 名称（超长省略号）+ 计数
    - 悬停显示操作按钮：✎ 编辑（重命名 / 改颜色）、× 删除
    - 底部「+ 新建分组」入口
  - 右侧任务列表
    - 任务卡片：勾选框 + 标题 + 备注 + meta 行（分组 chip / 优先级 chip / 截止时间 chip / 创建时间 ghost chip / 完成 chip）
    - 点击卡片主体打开详情编辑弹窗；勾选框与悬停操作按钮独立响应
  - 底部状态栏
    - 左侧：任务统计（口径与右侧列表完全一致：当前分组 + 筛选 + 搜索）
      - 文案示例：「全部任务：共 8 个任务，5 个进行中，3 个已完成」
    - 右侧：MCP 指示器（仅 MCP Server 运行时显示，绿点 + 「MCP 已开启」）+ 版本号 v1.0.0
- 信息密度：紧凑桌面风格（13px 基准字号），全局禁止文本误选中（仅输入框可选中）

## 核心功能

- 任务管理
  - 新建任务（标题必填 + 备注可选）
  - 编辑任务（点击任务条目直接打开详情编辑，也可通过悬停的编辑按钮）
    - 查看与编辑合一（清单类工具主流做法），弹窗右上角有 ✕ 关闭按钮
  - 删除任务（支持二次确认）
  - 勾选完成 / 取消完成
  - 时间字段
    - 创建时间：系统自动记录（时间戳）
    - 截止时间：手动设置，可选，日期 + 具体时间（`datetime-local`）
    - 完成时间：勾选完成时自动记录，取消完成时清除
    - 创建 / 完成时间为系统管理字段，编辑弹窗中只读展示、不可修改
- 任务组织
  - 任务分组（如：工作 / 生活 / 学习）
  - 分组颜色
    - 创建分组时可从 8 色预设色板选择 + 「默认颜色」选项
    - 色板：玫瑰红 / 琥珀 / 绿 / 青 / 蓝 / 紫 / 粉 / 灰
    - 侧边栏分组名前显示 8px 颜色圆点（无颜色为中性灰点）
    - 任务卡片分组 chip 跟随分组颜色软着色（色底约 11% 透明度 + 同色文字）
  - 分组编辑：悬停分组显示编辑按钮，支持重命名（自动联动该分组下的任务、当前视图与颜色记录）与修改颜色
  - 分组删除：二次确认，任务归入「未分组」，同步清理颜色记录
  - 分组支持拖拽排序（顺序持久化到 groups 数组）
  - 优先级标记：高 / 中 / 低（高优红色调、中优琥珀色调软色底 chip）
  - 截止时间（可选，日期 + 具体时间）
    - chip 展示：带时间用 ⏰、纯日期用 📅；相对描述（今天 / 明天截止）
    - 悬停 chip 显示完整截止时间
    - 逾期：带时间按具体时刻判断，纯日期按天判断；红色 ⚠ 标记受「逾期高亮」设置控制（关闭时仍显示普通截止 chip）
- 任务浏览
  - 列表视图（默认）
  - 筛选：全部 / 进行中 / 已完成
  - 排序：自定义排序 / 按优先级 / 按截止时间 / 按创建时间
  - 任务拖到侧边栏分组上可快速移动分组
  - 关键字搜索（匹配标题和备注）
- 排序规则说明
  - 通用规则（适用于所有规则排序）
    - 已完成的任务整体排在未完成之后（两段内部再按所选规则排序）
    - 排序是纯视图计算，不修改任务数据
  - 按优先级：高 → 中 → 低；同优先级按创建时间（先建的在前，依赖稳定排序）
  - 按截止时间：早的在前；未设置的排最后；逾期判断带时间的按具体时刻、纯日期按天
  - 按创建时间：先建的在前
  - 自定义排序
    - 按任务 `order` 字段排序，没有 `order` 的回退为创建时间（`ord()` 兜底函数）
    - `order` 仅在拖拽时写入（中点插值算法，每次只改被拖任务 1 个字段）
    - 新建任务自动置顶（`order` = 当前最小有效顺序值 - 1）
    - 拖动任务自动切换到自定义排序，手动顺序持久化，可随时切回规则排序（切回后顺序不丢失）
    - 自定义模式所见即所排，不强制已完成沉底
    - `order` 生命周期：创建时赋初值 + 拖拽时更新，其余操作（规则排序 / 完成 / 编辑 / 跨组移动 / 删除）只读或无视
- 侧边栏与状态栏计数规则
  - 数字 = 该分组在当前筛选（tab）和搜索条件下的任务数，与右侧列表、状态栏统计三者共用同一取数口径
  - 悬停显示「当前筛选下的任务数：N」

## 数据存储设计

- 双 JSON 文件模型（与 VSCode 的 settings.json 思路一致）
  - 任务数据：`tasks.json`
  - 应用设置：`settings.json`（两者互不影响）
  - 均存放于 `app.getPath('userData')`（`AppData\Roaming\sylvie-tasklist\`）
- tasks.json 结构
  - `groups: string[]`：分组名数组，数组顺序即侧边栏分组顺序（拖拽直接改此数组）
  - `groupColors: Record<string, string>`：分组名 → hex 色值（旧数据自动补空对象）
  - `seq: number`：任务 id 自增计数器
  - `tasks[]`：
    - `id: number` 唯一标识
    - `createdAt: number` 创建时间（毫秒时间戳）
    - `order?: number` 自定义排序顺序值（稀疏字段，仅拖拽过才写入；无值回退 `createdAt`）
    - `done: boolean`
    - `completedAt: number | null` 完成时间（旧数据兼容：无字段显示「已完成」不带时间）
    - `title: string` / `note: string`
    - `group: string` 分组名（弱引用，按名字关联；分组删除时归入「未分组」）
    - `priority: 'high' | 'mid' | 'low'`
    - `dueAt: string` 截止时间 ISO 格式 `YYYY-MM-DDTHH:MM`，未设置为空串（旧纯日期数据自动补 `T09:00`）
  - 时间字段命名规范：统一带 `At` 后缀（`createdAt` / `dueAt` / `completedAt`），旧键名（`created` / `due`）加载时自动迁移
- 本地文件持久化，启动时自动加载
- 修改后自动保存（防抖）
- 任务数据备份：手动导出 / 导入 `tasks.json`（导出文件名即 tasks.json）
- 设置文件 settings.json
  - 配置键采用点分命名空间（分类.名称），扁平结构，与 VSCode 风格一致
    - `appearance.*` 外观、`window.*` 窗口、`task.*` 任务、`mcp.*` MCP 服务
  - 未知配置键忽略，不报错（仅覆盖合法键）
  - 旧版扁平键名自动迁移到命名空间键名
  - 设置界面可编辑 JSON 原文（保存修改 / 放弃修改 / 导入 / 导出 / 恢复默认）
  - GUI 修改即回写 JSON，JSON 修改即刷新 GUI（双向同步）
- 视图状态（第三层，不入两个 json 文件）
  - 当前分组、筛选 tab、排序模式等会话性 UI 状态
  - 数据层 / 配置层 / 视图状态层三层分离（VSCode workspace state 思路）

## 设置界面设计

- VSCode 风格设置页
  - 顶部搜索框：即时过滤设置项，左侧导航显示各类别命中数量
  - 左侧分类导航（7 类）：通用 → 外观 → 任务 → MCP 服务 → 数据与备份 → 配置文件 → 快捷键
  - 右侧设置项列表：标题 + 说明 + 右侧控件（下拉框 / 复选框 / 滑动开关），改动即时生效并持久化
- 设置项明细（默认值）
  - 通用
    - `window.closeAction`：点击关闭按钮时——最小化到系统托盘（默认）/ 退出应用
  - 外观
    - `appearance.theme`：主题——亮色（默认）/ 暗色 / 跟随系统（监听系统深浅色变化）
    - `appearance.fontSize`：界面字号——小 90% / 标准 100%（默认）/ 大 110%
  - 任务
    - `task.defaultGroup`：新建任务默认分组（候选 = 所有自定义分组 + 未分组，未分组始终可选）
    - `task.defaultPriority`：默认优先级——中（默认）
    - `task.overdueHighlight`：逾期任务高亮（默认开，关闭仅影响红色 ⚠ 标记）
  - MCP 服务
    - `mcp.serverEnabled`：启动 MCP Server（滑动开关，默认关，切换立即生效无需重启）
  - 数据与备份
    - 数据 / 设置文件路径展示（只读）
    - 导出备份 / 导入备份 / 打开数据文件夹
  - 配置文件
    - settings.json 编辑器（等宽字体文本框）+ 保存修改（校验后写盘）/ 放弃修改 / 导出配置 / 导入配置 / 恢复默认（二次确认，不影响任务数据）
  - 快捷键：键位表只读展示
- 弹窗交互：右上角 ✕ 关闭 + `Esc` + 点击遮罩空白处关闭（三种方式）

## 交互体验设计

- 键盘快捷键
  - `Ctrl+N`：新建任务
  - `Ctrl+F`：聚焦搜索框
  - `Ctrl+,`：打开设置
  - `Esc`：关闭弹窗 / 菜单
- 操作提示
  - 所有关键按钮带悬停 tooltip（title）：新建、筛选、排序、勾选、编辑、删除、窗口控制、设置页各按钮等
- 操作反馈
  - 全局 toast 提示（窗口内底部中央，滑入动画）
  - 勾选完成 / 取消完成：任何筛选视图统一反馈——卡片绿色 / 蓝色闪烁 + toast「已完成『任务名』」
  - 列表排序变化使用 FLIP 位移动画（卡片从旧位置平滑滑到新位置，0.28s），完成沉底不再生硬跳变
  - 拖拽排序：被拖卡片半透明、目标位置蓝色虚线高亮
  - 危险操作（删除任务 / 删除分组 / 导入覆盖 / 恢复默认设置）均二次确认
- 空状态提示（按场景区分）
  - 搜索无结果：「没有匹配的任务，换个关键词试试」
  - 已完成筛选：「还没有完成的任务」
  - 进行中筛选：「所有任务都已完成 🎉」
  - 无任务：「暂无任务，点击「新建任务」开始吧」
- 动效（克制原则）
  - 窗口启动淡入、弹窗缩放淡入、下拉菜单滑出
  - 按钮 / 卡片悬停微反馈、输入聚焦光圈
  - 主题切换平滑过渡（0.22s）
  - 尊重系统「减少动态效果」设置（开启时跳过所有动画）

## MCP 服务设计

- 设置中开关控制（立即生效，无需重启）
- 通过标准 MCP 协议将任务数据暴露给 AI 助手等外部客户端
- 能力：查询任务、创建任务等（只读为主，v1 保持最小能力集）
- 运行状态在状态栏右下角以绿点指示器呈现
- 实现方向：主进程托管 MCP server（本地端口），渲染进程无需感知

## 非功能需求

- 安装包（Electron Forge Makers，仅 Windows）
  - Windows（Squirrel.Windows）
- 启动速度 < 2s
- 无网络依赖（纯本地应用）
- 数据文件损坏时自动降级为空数据并提示
- 无障碍与细节
  - 关键操作均有 tooltip 提示，危险操作有明确风险说明

## v1 范围外（暂不实现）

- 多设备云同步
- 多用户 / 账户体系
- 子任务与依赖关系
- 日历视图
- 提醒通知
- 开始时间 / 日程规划（任务清单不做日程管理，v2 可在现有字段上扩展可选开始日期，数据结构向后兼容）
- toast 队列（连续操作时提示互相覆盖为原型简化，正式开发可升级）
